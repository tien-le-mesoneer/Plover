# UI Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Collapsible collections, a resizable request/response split, request history, value-only copy for variables and params, and quieter hover/focus-revealed buttons.

**Architecture:**
- Layout state grows two fields: `UiState.collapsed` and `LayoutState.split_permille`.
- One server route, `resolve-text`, resolves `{{…}}` for copying. It keeps secrets out of the page until the user confirms.
- Send history is a new core store, `send_history.rs`, next to `run_history.rs`. It reuses `ResultRecord` and `Masker`. It is fed by the send handler and shown in a History tab built like run tabs.

**Tech Stack:** Rust (plover-core, plover-server/axum, ts-rs bindings), React + zustand + vitest, Monaco.

**Spec:** `docs/superpowers/specs/2026-10-27-ui-round-2-design.md`

**Order:** run this after `2026-10-24-follow-up-gaps.md` (see the spec, "Interaction"). Task 0 re-checks whatever that plan changed.

## Global Constraints

- `KEEP_SENDS = 100`, global across collections. Bodies are capped by the existing `MAX_DETAIL_BODY` (1 MiB).
- Send records are masked with `Masker` **before** they are written. The page never receives unmasked history.
- `resolve-text` returns `text: null` whenever the result contains a secret and `reveal` is false.
- Copy confirmation text: `This value is a secret. Copy anyway?`, using the same `window.confirm` as Copy as cURL.
- Split ratio: `splitPermille` 200..=800, `null` = 500. Arrow key step is 20 (2 %). Minimum pane size is 240 px side by side and 120 px stacked. The stacked breakpoint is `(max-width: 1100px)`, unchanged.
- Hidden-until-hover controls use `opacity` (never `display: none`). They show on `:hover`, `:focus-within` and `@media (hover: none)`, and keep the Tab order.
- Targets are at least 24 × 24 px, every icon button has an `aria-label`, focus is visible, and icons are SVG only (no emoji).
- Variable copy shortcut: `⌘/Ctrl+Shift+C`. Live note: `Copied value of {{name}}`.
- History is never remembered as an open tab across restarts, and there is one History tab at most.
- Tests use a temp `PLOVER_STATE_DIR` and `PLOVER_KEYCHAIN_SERVICE=dev.plover.test`.

**Gate (before every commit, `set -o pipefail`):**
```bash
cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace --no-fail-fast \
 && (cd frontend && npm run typecheck && npm run lint && npm test && npm run build && npm run check:no-cdn && npm run check:console)
```
Regenerate bindings after DTO changes: `PLOVER_UPDATE_BINDINGS=1 cargo test -p plover-server --test bindings`.

## Review Focus

1. **A secret in a param or var copied without asking.** `{{token}}` is runtime, sent in `Authorization`, and now masked. Copy must ask first, and the first response must carry no value. Tested in Task 3 (server) and Task 5 (UI).
2. **A history file holding a secret.** Send with an env secret in a header, the body and the query, then grep the files under `<state>/sends/`. Tested in Task 6.
3. **Collapsed collection plus the filter.** Typing a filter while collapsed must show the matches. Clearing it must restore the folded state. Tested in Task 1.
4. **Old state files.** Without `collapsed` or `splitPermille` they load as defaults, and an out-of-range `splitPermille` is rejected by `PUT /layout` (400). Tested in Tasks 1 and 2.
5. **Hidden buttons unreachable by keyboard.** Tab must reach Run/Reload/Close on a collection header, and the corner Copy in the response. Tested in Tasks 4 and 8 (`a11y.test.tsx`).
