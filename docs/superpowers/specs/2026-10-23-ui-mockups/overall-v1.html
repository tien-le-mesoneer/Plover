B. Runner là khung dưới (như hiện tại, nhưng kéo giãn được)

Vừa xem kết quả vừa sửa request. Khung hẹp hơn, 400 dòng phải cuộn nhiều.

Chung cho cả hai

  • Chạy cả collection / 1 folder: nút ▶ hiện khi rê chuột lên tên collection hoặc folder (như hiện tại). ▶ có menu nhỏ: Run · Run with data…
  • Chạy 1 request: Send hoặc ⌘Enter. Kết quả ở khung Response bên phải.
  • Từ Runner quay về request: icon ↗ ở mỗi dòng mở request đó thành tab, giữ nguyên kết quả của lần chạy.
